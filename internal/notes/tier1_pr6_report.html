New capability

u1 = sc.index_add(c, [0, 1], x * c[2:4])                       # add at fixed indices
cn = sc.index_set(u1, [n-1, n-2], sc.stack([u1[0]*0.5, u1[1]+u1[2]]))  # store at fixed indices
(final,) = sc.scan(step, c0, xs, length=N)                     # step's carry is updated in place
  • sc.index_add and sc.index_set are new operations. index_add(b, i, v) equals b + scatter(v, i, b.shape), but it is kept as a single update. Both have forward and reverse derivatives, exact sparsity, constant folding and a verifier rule.
  • In place: when a scan or while_loop body's next carry is a chain of these updates rooted at the carry, and the rule below holds, the body lowers to an <name>_inplace procedure. The loop calls it with the same pointer for the carry in and the carry out, the carry has one slot, and each step writes only the indexed entries: 
    static inline void acc_inplace_raw(const double* c, const double* x, double* cn, double* w) {
  for (u = 0; u < 2; ++u) cn[u] = cn[u] + x[u] * c[2 + u];   // index_add: 2 writes
  cn[n-1] = cn[0] * 0.5;  cn[n-2] = cn[1] + cn[2];            // index_set: 2 writes, reading the fresh values
}
for (k = 0; k < N; ++k) acc_inplace_raw(s0, xs + 2*k, s0, NULL);
  • The rule (in_place_chain, sufficient rather than necessary). Anything else keeps the two-slot carry and gives identical results.
    • The values of update i read no chain link except the one just before it.
    • Those values read none of the entries update i writes. A read through a comparison, a select, a cast or a nested loop counts as reading every entry, because derivative patterns cannot see it.
    • No other output reads any chain link.
  • What the in-place body gives up:
    • It is never scalarized. Scalar expansion models the carry input and output as separate buffers, and only the caller's aliasing makes reading the output before writing it defined. This is the minimum part of C-54 the change needs.
    • The ordinary body procedure is still generated for any other call site that passes separate buffers.
    • Reverse mode stores every carry, so it never uses the in-place body.

Deviations and notes

  • The plan described index_add and index_set as builders recognised at lowering. They are real operations instead. That keeps the chain visible through simplification, gives them an O(|idx|) lowering outside loops as well, and makes their derivatives exact.
  • The rule is deliberately conservative. Tier 2's left-looking LDLᵀ reads earlier columns and writes the current one, which satisfies it. Anything the rule rejects still works, just with two slots.
