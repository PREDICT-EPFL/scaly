Tier 2 · PR 6 report

T2-6 · generated dense kernels (C-106) · branch claude/tier2-sparse · 26 Sep 2026

Summary. Three new expression ops, each lowered to plain loops:

  • cholesky;
  • ldl: L D Lᵀ without pivoting, packed into one matrix;
  • solve_triangular: lower or upper, transposed or not, unit diagonal or not, one right-hand side or many.

Orders up to 8 become straight-line code. All three ops have derivatives in forward mode (one seed or many) and reverse mode, and to second order. scaly.linalg adds cho_solve, ldl_solve, ldl_unpack and solve.

Gate: at most 2× LAPACK at n = 32–64.

  • Met at -O3: Cholesky 1.5×, L D Lᵀ 1.2×, triangular solve 0.3×, multi-right-hand-side solve 1.3×, matmul 1.6×, all against OpenBLAS. Below n = 32 everything is faster than LAPACK, which carries about 1 µs of dispatch overhead per call.
  • Met at the JIT's default -O2 for the factorizations and the vector solve.
  • Missed at -O2 for the multi-right-hand-side solve (3.5×) and matmul (3×). gcc 11 does not vectorize at -O2; clang does. This is recorded as decision C-107.

Suite: 1 298 passed, 88 skipped; the same four VM-only failures. ruff, ty and the docs build are clean. Mutation checks: 11 of 11 killed, after one test was added.

1. What was built

PieceDetails
Ops (ir/expr.py)
  • CHOLESKY and LDL read the lower triangle of a square float matrix.
  • TRISOLVE(T, B) takes attrs lower, trans and unit, with B a vector or a matrix.
  • Each op has a verify rule.
Lowering, loops
  • Factorizations run row by row (Crout). Entry (i, j) is the matrix entry minus a dot product of rows i and j, both contiguous. For L D Lᵀ, row i is kept scaled by D in a scratch vector, so each term is one multiply-add.
  • Dot products use four interleaved partial sums (_blocked_sum) plus a tail.
  • T X = B uses the dot form. Tᵀ X = B sweeps rows of T (axpy form), so it stays contiguous.
  • With a matrix of right-hand sides, each step handles a whole row of X, with four rows of the triangle per pass.
  • Loop bounds are triangular expressions of the outer index, so the code size does not depend on the order.
Lowering, unrolledFor order ≤ DENSE_UNROLL = 8 the same algorithms are emitted with constant indices, which scalar expansion turns into registers.
Derivatives
  • Factorization tangents: X = L⁻¹ S L⁻ᵀ, with S the symmetric matrix whose lower triangle is dA's. Then dL = L Φ(X) for Cholesky, and dD = diag X, dL = L stril(X) D⁻¹ for LDLᵀ.
  • Factorization cotangents: G = L⁻ᵀ P L⁻¹ and Ā = tril G + stril Gᵀ, where P = Φ(Lᵀ L̄), or stril(Lᵀ stril(F̄) D⁻¹) + diag F̄ for LDLᵀ.
  • Solves: op(T) dX = dB − op(dT) X, B̄ = op(T)⁻ᵀ X̄, and T̄ = −B̄Xᵀ (or −X B̄ᵀ) restricted to the triangle.
  • In multi-seed mode, every seed becomes a column of one solve.
SparsityConservative: the lower triangle of a factor may depend on all of the lower triangle of its input. Column c of a solution may depend on column c of B and on the whole triangle read.
DocsNew guide page guide/linalg.md; IR op table; codebase map.

2. Tests

tests/linalg/test_dense.py has 100 tests.

  • Factorizations at seven orders straddling the unroll threshold (1, 2, 3, 8, 9, 13, 20; all remainders mod 4) match NumPy. The upper triangle is never read: 100× noise placed there changes nothing. The factor's upper triangle is zero.
  • Solves. All eight flag combinations × seven orders × vector and matrix right-hand sides match numpy.linalg.solve.
  • Composed solves. cho_solve, ldl_solve, solve and ldl_unpack are correct. An indefinite matrix gives NaN from Cholesky.
  • Derivatives for ten ops at orders 4 and 10:
    • gradients in the matrix and the right-hand side match finite differences;
    • the multi-seed Jacobian equals the gradient in strict mode;
    • Hessians in the right-hand side match finite differences, and Hessians in the matrix are symmetric;
    • single-seed jvp equals Jacobian × direction.
  • Sparsity. The Jacobian lies inside the pattern, and the columns of a multi-RHS solve stay independent.
  • Code shape. The unrolled code has no loops, and the loop code has the same size at n = 24 and n = 48.
  • Other. Validation of shapes and dtypes; vmap over a Cholesky; the scaly.linalg exports.

Mutation checks (11 of 11 killed):

  • Φ's halved diagonal, in forward and in reverse mode
  • symmetric completion of the lower tangent
  • the transposed dT term
  • the transposed outer product in the solve cotangent
  • cotangent symmetrization
  • the blocked-sum tail
  • LDLᵀ's scaled row
  • the seed-column layout
  • solve sparsity per column
  • the unrolled upper range

The single-seed transposed tangent first survived because every test went through the multi-seed path; a direct jvp test was added.

4. Decision for you (C-107)

Should the JIT's default become -O3? Alternatively, add -ftree-vectorize for gcc only. Either would remove the only gate misses and benefit every generated loop on Linux. The cost is somewhat longer compiles and a new cache key.
