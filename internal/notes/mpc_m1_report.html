Summary. scaly.mpc exists.

  • Problems. An OCP combines:
    • a continuous model with any transcription, or a discrete map;
    • Function or Quadratic costs, at the points or integrated;
    • state and control bounds, and hard or soft path constraints;
    • a terminal equality;
    • parameters by name, some varying per stage.
    From these it builds an sc.problem.
  • Controllers. MPC solves it with IPOPT, SQP or PIQP. Its law is one Function, the solver nested and the warm-start shift in its code, ready for write_module. simulate runs a closed loop.
  • The gate. The cart-pole built by scaly.mpc is the hand-written NLP: the same solution to 1e-9, the same 23 IPOPT iterations, 0.97–0.99× the time.
  • Fixed on the way: the forward rule for a matrix product kept a structural dependence through a zero tangent. That stopped PIQP from proving any QP whose dynamics go through a Function call.

Suite: 3 089 passed, 42 skipped, 52 xfailed. The one failure is Colin's uncommitted tiny_qp test. ruff and ty are clean on every path touched. Mutation checks: 18 of 18 killed; one after a test was added.

1. What was built

PieceDetails
mpc/ocp.py
  • OCP(ode=|step=, horizon, dt, transcription, stage_cost, terminal_cost, x_bounds, u_bounds, constraints, terminal, varying, cost, name).
  • Parameters. They are the union, by name, of every Function's inputs after (x, u) (after x for a terminal cost), plus Quadratic and TerminalEquality references given as names. Shapes are checked to agree. Each Function is wrapped over the whole list (_over), so the transcription sees one signature.
  • Variables. G(xs, us, [zs], [slack]); stage-major, so every stage is one vmap. The problem's parameters are (x0, p), with every named parameter packed into p.
  • Costs. "points" gives dt Σ l(x_k, u_k) for a model, Σ l for a map. "integral" gives the transcription's quadrature, and is the default for pseudospectral segments, whose inner controls the points would leave out of the cost.
  • Constraints.
    • Bounds cover every state but x_0, the transcription's internal states and controls included.
    • Path constraints hold at stages 0..N−1, as in acados. A soft one gets two bounded groups and an exact l1 penalty.
    • TerminalEquality.
  • _Layout knows where every block sits, and which multiplier runs are per stage.
mpc/controller.py
  • MPC(ocp, solver, options, name): solve returns a Solution (states, controls, internal variables, slacks, times, cost, status, the primal-dual point); __call__; initial_guess; reset; status.
  • The warm start is one flat vector: [primal, box multipliers, equality multipliers, inequality multipliers]. shift moves each per-stage block up one stage and repeats the last. The initial state's and the terminal set's multipliers stay.
  • law(x0, *params, guess) → (u, guess_next) calls the solver symbolically and shifts in its own code. Python's __call__ runs this same compiled law, so Python and C cannot disagree.
  • simulate(controller, plant, x0, steps, **params) returns a ClosedLoop. A parameter may be a function of the step.
integrators/transcription.pyInterval.fn now returns the residuals and the cost as two outputs. A map of the residuals is then a map, which keeps I5's stage-wise sparse Jacobian. A residual-plus-cost vector sliced apart would be a gather, and the Jacobian would fall back to whole-horizon coloring.
ad/forward.pyThe single-seed matrix-product rule adds dA @ x only when dA is not a zero constant, as the multi-seed rule already did. zeros @ x made a linear model's tangent read x, and the QP proof reads that as not affine, so PIQP refused every OCP with a model behind a call.
DocsA new guide page docs/guide/mpc.md (problems, costs, constraints, parameters, the controller and its law, a table of solvers) and an API page docs/api/mpc.md, with nav entries.

2. Tests and mutation checks

tests/mpc/ has 16 tests.

  • The gate. The cart-pole (soft track limits, two RK4 substeps), written by hand without scaly.mpc or scaly.integrators, is the same NLP. States, controls and slacks agree to 1e-9.
  • Transcriptions. Shooting and Radau collocation agree to the integrators' errors. Pseudospectral does at least as well (its controls are free inside intervals) and within 5%.
  • Problems.
    • A varying reference is read stage by stage: zero-cost tracking, exact.
    • Parameters are the union of what the Functions name, with the shapes checked.
    • A discrete map's costs are summed, and its terminal equality holds.
    • A soft constraint is zero when it can hold, and exactly the violations when it cannot.
    • State bounds hold after x_0, which may lie outside them.
    • u_ref is honoured.
    • Pseudospectral's inner controls reach both bounds.
    • The refusals.
  • Controller.
    • The shift's layout, block by block, multipliers included.
    • The law equals whole solves with their shifted warm starts, over four steps.
    • A PIQP closed loop reaches the origin within its limits.
    • A pendulum stabilized with an si.adaptive plant.
    • A parameter changing with the step.
    • The law renders as one C module with its solver.
    • The initial guess.
