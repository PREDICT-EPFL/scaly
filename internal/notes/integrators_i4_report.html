API-145 · exact, adaptive and symplectic integrators · branch claude/integrators-mpc · 27 Sep 2026 · plan integrators_mpc_plan_2026_09_27.md

Summary. The rest of the integrator catalogue:

  • Exact discretization of linear systems. si.zoh and si.foh each read their matrices off one matrix exponential, and match the exact flow to 1e-11.
  • Linearization. si.linearize gives one Jacobian per input leaf of any model or map, as generated code.
  • Adaptive simulation for plant models. si.adaptive uses Dormand-Prince 5(4) or Bogacki-Shampine 3(2), with error control inside the generated code.
    • It reaches solve_ivp's RK45 accuracy at every tolerance from 1e-4 to 1e-10, 20–140× faster per Python call.
    • It returns NaN rather than a short result when the step budget runs out.
    • Its derivatives hold the step sequence.
  • Symplectic methods. si.symplectic offers Störmer-Verlet and symplectic Euler. Over 10⁵ pendulum steps their energy error stays bounded, where RK4 loses 0.44 of a potential spanning 2.

1. What was built

PieceDetails
integrators/linear.py (new)
  • zoh(A, B, dt) reads expm([[A, B], [0, 0]] dt).
  • foh(A, B, dt) reads expm([[A, B, 0], [0, 0, I/dt], [0, 0, 0]] dt) and returns (Ad, B0, B1) for x⁺ = Ad x + B0 u + B1 u⁺.
  • linearize(f, *point) gives sc.jacobian per input leaf, evaluated at the point. It takes templates, and grouped parameters as one argument each.
si.adaptive (explicit.py)
  • The loop. A while_loop whose carry is [x, t, h]:
    • each iteration attempts min(h, dt − t);
    • the error is the RMS of (x_high − x_low) / (atol + rtol max(|x|, |x_high|));
    • a step is accepted when that error is at most 1.
  • _controller. The next factor is 0.9 err^(−1/(q+1)) within [0.2, 5], rounded to a power of 2^(1/1024) by casting its exponent to int64. The cast carries no derivative, which is how the step sequence is held for derivatives without a stop-gradient op in the IR.
  • NaN at the step bound. max_steps bounds accepted and rejected steps together. If it is reached before dt, the result is NaN.
  • The interval. dt is folded in or taken as an input, as elsewhere.
si.symplectic (explicit.py)
  • For x = [q, v], split = len(q).
  • Störmer-Verlet: a half kick, a drift and a half kick.
  • Symplectic Euler: a kick and a drift.
  • Each half is read from one call of the model at the state it needs.
DocsSections on adaptive steps, symplectic methods and linear systems in docs/guide/integrators.md, and the API entries.

2. Tests and mutation checks

  • Linear systems.
    • ZOH and FOH against a DOP853 solve at 1e-13 of the held or ramped input, to 1e-11.
    • Bd = A⁻¹(Ad − I)B, and FOH reduces to ZOH for a constant input.
    • Scalar systems; the refusals.
  • linearize. Analytic Jacobians of a grouped-parameter model; a map against finite differences; a template.
  • Adaptive accuracy. Both pairs are checked at three tolerances, the error decreasing with the tolerance: DOPRI5's error below 0.5× the tolerance, BS32's below 5×. A first step as long as the whole interval must be rejected, and the result is as accurate.
  • Adaptive behaviour.
    • NaN when the steps run out.
    • A folded dt equals an input one.
    • dt = 0 returns x.
    • An explicit h0.
    • Growth capped at 5×: with a constant derivative the error is zero, so from 2⁻²⁰ exactly ten steps reach t = 1. Nine fail and ten succeed.
    • The controller law at err = 0, 1e-12, 1, 32 and 1e30.
    • The rounded factor has a zero derivative.
  • Adaptive derivatives. Jacobians in x and u against finite differences; d/d dt = f(x(T)) to the step's accuracy; reverse mode equals forward mode.
  • Symplectic.
    • Energy bounded over 10⁵ steps for both methods, where RK4 dissipates.
    • Orders 2 and 1 against DOP853.
    • Jacobians; the refusals.
