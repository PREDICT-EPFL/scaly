New capability

Sparse kernels over a fixed pattern can now be written directly:

Ax  = sc.segment_sum(a * sc.gather(x, cols), rows, m)      # SpMV from the nonzero data vector a
ATy = sc.segment_sum(a * sc.gather(y, rows), cols, n)      # its transpose, same pattern
cn  = sc.segment_max(abs_vals, cols, n)                    # column ∞-norms (Ruiz scaling)
  • sc.scatter now accumulates repeated indices, as its docstring always said. It used to raise.
  • sc.segment_sum is a builder over scatter.
  • sc.segment_max and sc.segment_min are new operations: fill is used for empty bins, NaN propagates within its bin, and ties follow sc.options(nonsmooth=…).
  • All three are differentiable, forward and reverse, with exact structural sparsity. The Jacobian of a SpMV with respect to the data vector comes out with exactly nnz entries.
  • Implementation picked from the pattern: the indices are fixed when the code is generated, so lowering chooses per pattern:
    • Distinct destinations become a plain store in a parallel GLOBAL loop, byte-identical to before.
    • Repeated destinations become out[d] = out[d] + v in a REDUCE loop.
    • Either way the destination is arithmetic where it is affine and a constant table otherwise; that part is the existing affine-index recovery.
  • gather adjoint: it is now one accumulating scatter. It used to be one gather-and-sum per source entry, an O(n·nnz) Python loop that emitted O(n) graph nodes.

Deviations from the plan

  • The plan listed four lowering variants: unique, affine, sorted pointer table, and general accumulate. The sorted-pointer-table variant is not implemented:
    • Its bounds come from loaded tables, and scalarize cannot expand loops with loaded bounds, so small procedures would lose scalarization.
    • The measured gap to SciPy is already under 2×.
    It can come back as a large-pattern-only variant if a Tier 2 kernel needs it.
  • The combine_scatter_sums audit found no change needed. The pass only matches scatters whose loop body is a plain load-store with distinct destinations, so an accumulating scatter never qualifies.
