Tier 3 · PR 0a report

T3-0a · test problems and the PIQP trace harness (C-123) · branch claude/tier3-ipm · 26 Sep 2026

Summary. The oracle side of Tier 3 is in place.

  • Problems. The 48 Maros–Mészáros problems with n + m ≤ 1000 (408 kB, Apache-2.0, stored as distributed), five infeasible problems and a linear-MPC generator. A loader maps them to PIQP's form.
  • Trace harness. A C driver runs vendored PIQP 0.6.2 and captures its per-iteration table, its result at full precision and its own timings. Truncated runs (max_iter = k) reproduce the full run exactly, so every iteration is available at full precision, σ included.
  • Findings the reference must reproduce. PIQP solves all 51 feasible problems with both backends, but the backends' iteration counts differ on 4 (QCAPRI: 84 sparse against 32 dense), so the trace gate must compare against one backend. On the infeasible set PIQP runs two primal-infeasible problems to the iteration limit, and reports an unbounded problem as primal infeasible.
  • A data trap. The set writes an absent bound as ±1e20 but sometimes stores it as 9.999999999999998e19. Read as finite, it sends PIQP's initial point to 1e37, and 4 problems fail. The loader treats |value| ≥ 1e19 as absent.

Suite: all tests pass on the Mac except the import-layering check, which trips only on local Jupyter checkpoints under src/ (untracked). ruff and ty are clean on tracked files. Mutation checks: 13 mutants, 12 killed (three only after a test was added). The 13th exposed dead code, a redundant infinity clamp, now removed.

1. What was built

PieceDetails
tests/data/maros_meszaros/
  • 48 .npz files with the distributed fields (P in full, q, r, A, l, u), plus the Apache-2.0 LICENSE and a NOTICE naming the source commit (c7d02f4f of qpsolvers/maros_meszaros_qpbenchmark).
  • Downloaded: the 85 smallest files, up to 1 MB. Kept: those with n + m ≤ 1000.
tests/solvers/ipm/problems.py
  • QP: PIQP's form, A x = b, h_l ≤ G x ≤ h_u, x_l ≤ x ≤ x_u. A single-coefficient-1 row becomes a bound (bounds intersect), an l == u row an equality, and every other row an inequality, kept even when infinite on both sides (PIQP counts those in μ).
  • infeasible_problems(): three primal-infeasible problems and two unbounded ones, each labelled with the true cause.
  • mpc_qp(nx, nu, N): simultaneous-form linear MPC with a random stable system, a fixed x₀ and boxes.
tests/solvers/ipm/piqp_trace.c, piqp_trace.py
  • The driver reads a binary problem file, runs the sparse or dense backend with verbose and timings on, and prints the per-iteration table, then every info field and every result vector with %.17g.
  • It is built once per source and toolchain with the JIT's flags and the plugin's include, lib and rpath flags.
  • run returns the parsed Trace. exact_trace returns ρ, δ, μ, σ and both step lengths for every iteration at full precision.
