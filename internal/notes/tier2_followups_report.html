Tier 2 · follow-ups before Tier 3

C-118 … C-121 · the Mac run, sparse matrices in Function signatures, derivatives in non-input expressions, examples · branch claude/tier2-sparse (after the tier2-complete tag) · 26 Sep 2026 · first Claude Code session

Summary.

  • Mac run (C-118). The first macOS run gave 1 575 passed and 2 failed. Both failures were one race: recompile() deleted a cache directory while another process was building into it. A build now restarts once in that case. ty found 30 diagnostics in the Tier 2 tests, now fixed.
  • sc.S(name, pattern) (C-119). A sparse matrix's pattern is now part of a Function's signature. The body receives a SparseMatrix. A call that passes another pattern, symbolically or as a SciPy matrix, is refused. Results come back as a SparseMatrix or a csc_array. The generated code is byte-identical to that of a Function over the values vector, and a test pins this.
  • A silent AD bug (C-120). Forward-mode and sparse derivatives with respect to a slice of an input returned zeros, with no error. The hanging-chain example exposed it: a Newton step inside a while_loop differentiates with respect to a slice of the carry. Fixed by putting a stand-in input in place of such a wrt at the entry points.
  • Six examples (C-121) of control, optimization and numerical solves, each checked against NumPy or SciPy.

Suite: 1 615 passed, 0 skipped on the Mac (Apple clang 21, Python 3.14.3). ruff and ty are clean except for untracked local files. Mutation checks: 28 mutants. 25 were killed, four of them only after a test was added. The other three were equivalent and exposed dead code, which was deleted.

1. What was built

ItemDetails
JIT cache race (C-118)
  • _build_artifact writes, compiles and renames inside _compile_into. If that raises and the cache directory is gone, it runs once more. A compiler error with the directory still present is raised immediately.
  • ty fixes: mypy-style # type: ignore[arg-type] became # ty: ignore[...]; Literal-typed parameters in the Tier 2 tests; SparseMatrix.block is now annotated to accept NumPy and SciPy blocks, as it already did at run time.
  • The handoff note's union recipe for the node-ID baseline contradicted conftest.py, which refuses stale ids. It now points to the documented recipe.
sc.S (C-119)
  • scaly.linalg.sparse.S is a Tree leaf, so the import layers still point down. It stores the pattern as a SparsityType in the order of the values, plus CSC arrays for the checks.
  • Trees gained infer(value), which resolves sc.S(name, ...) from the traced body, and sparsities. Function.__init__ passes those sparsities on as the output metadata, the same route _from_exprs(output_sparsities=...) already took.
  • SymbolicValue marks library values that stand for an Expr leaf. SparseMatrix is one, so fn((K, x)) dispatches symbolically.
  • Evaluations accept any SciPy format. Float64 CSC is used as it is, and a non-canonical matrix is canonicalized on a copy, never in place. Explicitly stored zeros count as stored. A pattern mismatch is reported by column, for example column 0 stores rows [0], expected [0, 2].
  • Derived Functions (gradient, lagrangian_hessian) keep the tree, so their sparse arguments are checked too.
Derivatives in non-input expressions (C-120)
  • ir.expr.independent(exprs, wrts) replaces every wrt that is not an input with a stand-in input and returns the map back.
  • Applied in jvp, jvp_many, vjp, vjp_many, jacobian_sparsity, sparse_jacobian_colored, sparse_jacobian_reference and sparse_hessian, including the compressed batch that triangle() reads later. hessian, jacobian, gradient and sparse_jacobian reach the guarded primitives.
  • Semantics: the wrt is independent, and other paths to the inputs are held fixed. That is what reverse mode already computed.
Examples (C-121)
  • mdp_value_iteration.py: a slippery-grid robot. Segment ops, while_loop, an int64 policy.
  • lasso_admm.py: compressed sensing by ADMM. A Woodbury x step with dense cholesky, and soft thresholding with copysign.
  • lqr_tuning.py: LQR weights for a quadrotor in a gust, tuned on a vehicle 20% heavier than modelled. The Riccati and closed-loop scans use the step index and a negative stride, with reverse mode through both.
  • truss_sizing.py: minimum-compliance design. put_add/take with the bar table as a run-time int64 input.
  • heat_control.py: optimal heating of a two-material plate. SparseLDL time stepping, and sc.S passes K between Functions.
  • hanging_chain.py: stiffness and mass from two photographs. Newton in a while_loop with an isfinite safeguard, and a custom_derivative implicit rule.
