## Context

identity and invocation attributes. `LowerCtx` collects used results once and the first sibling
lowers all of them. Custom-rule residuals belong to the same invocation. `callees_of` owns
callee discovery, including the walks in differentiation and sparsity analysis. No carried
ranges, new loop operation, external calls or fusion changes.

keys so differently sized siblings group. Record this departure in the roadmap in this PR.
`function/model.py` currently contains no hard-coded call/map set; check again after rebase.
